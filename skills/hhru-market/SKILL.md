# hhru-market — анализ рынка

Анализ рынка — **read-only** для hh.ru. Ничего не меняет ни на hh.ru, ни
локально (кроме локальной истории `vacancies_seen`, которую `search` наполняет
как побочный эффект сбора). Запускай без подтверждения.

## Шаг 1 — собрать вакансии (search, READ)

```bash
hhru search --resume <id> --dry-run --max-pages N
```

`search` собирает карточки вакансий по фильтрам из конфига и наполняет
локальную историю `vacancies_seen`. `--dry-run` — без откликов (search и так
не откликается, но dry-run явно показывает, что это только сбор). `--max-pages N`
ограничивает объём.

## Шаг 2 — агрегаты рынка (market, READ)

```bash
hhru market
```

Сравнение сфер по медианной зарплате (по данным, собранным `search`). Флаг
`--estimates` достраивает медиану эвристическими оценками для вакансий без
указанной ЗП (помечаются `~`). Пустой рынок — подсказка запустить `search`.

## Шаг 3 — точечные запросы (query, READ)

```bash
hhru query "SELECT ..."
```

`query` — read-only SELECT к `history.db`. Полезен для распределения ЗП,
топ-компаний/требований. Только `SELECT`/`WITH ... SELECT` — не пиши мутаций.

## Правила

- **Никаких эмодзи.** Вывод CLI — только текст и ASCII-таблицы.
- **Read-only для hh.ru.** Не запускай `apply`/`bump`/`run` в рамках анализа
  рынка — это отдельный воркфлоу (см. `hhru-apply`).
- **Не используй `page.request.*` и внутренние API hh.ru** — только команды бота.
