# hhru-monitor — мониторинг и статус

Мониторинг — **read-only** для hh.ru. Ничего не меняет ни на hh.ru, ни локально.
Запускай без подтверждения.

## Статус сессии и резюме

```bash
hhru whoami
hhru list-resumes
```

`whoami` — действительность сессии + сводка аккаунта (откликов сегодня, новых
ответов 24ч, приглашений). `list-resumes` — резюме из конфига (и `--remote` —
реальные резюме аккаунта с hh.ru, read-only).

## Ответы работодателей

```bash
hhru responses
```

Мониторинг ответов/приглашений работодателей. `--resume <id>` — по конкретному
резюме.

## Воронка откликов

```bash
hhru funnel
```

Воронка откликов (сколько откликнулся, ответили, пригласили). `--resume <id>` —
по конкретному резюме.

## Статистика

```bash
hhru stats
```

Сводка и экспорт истории откликов. Флаг `--format csv|md|table` — формат вывода;
`--list` — список последних действий вместо сводки. Экспорт в файл (`-o <file>`) —
у команды `query`, не у `stats`.

## Правила

- **Никаких эмодзи.** Вывод CLI — только текст и ASCII-таблицы.
- **Read-only для hh.ru.** Не запускай `apply`/`bump`/`run` в рамках мониторинга.
- **Не используй `page.request.*` и внутренние API hh.ru** — только команды бота.
