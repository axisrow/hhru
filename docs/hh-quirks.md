# Известные особенности hh.ru

- **Телефон на экране `common` визарда черновика** (живой факт 2026-09-08):
  SMS-подтверждение требуется ТОЛЬКО для номеров России, Беларуси, Казахстана
  и Узбекистана («Для вашего телефона подтверждение не требуется. Мы
  подтверждаем телефоны только из России, Беларуси, Казахстана и
  Узбекистана» — ответ hh.ru на номер из Китая). Номера остальных стран
  hh.ru принимает без кода — для черновика без доступа к реальной SIM
  не-CIS номер в `common --phone` проходит экран без SMS.
- Пока на аккаунте есть незавершённый черновик, hh.ru не даёт создать
  новое резюме: вход в визард редиректит на экран дозаполнения существующего
  черновика (`create-resume` честно падает до кликов).
