# Тестирование

Каждый файл тестов имеет ровно один маркер категории:

- `unit` — чистая логика без сети;
- `integration` — связки модулей на моках и HTML-фикстурах;
- `smoke` — быстрая проверка сборки или CLI;
- `e2e` — сквозной путь на фикстурах без сети;
- `live_read` — чтение живого hh.ru;
- `live_write` — мутация живого аккаунта hh.ru.

Обычный `pytest` безопасен по умолчанию: live-тесты исключены из сбора. Тесты
без `live_*` также получают защиту от случайного вызова `browser.launch_context`.

Для чтения живого сайта запускайте явно `pytest -m live_read`. Мутационные
тесты запускаются только через шлюз `./scripts/live_test.sh`; каждый его вызов
требует отдельного подтверждения harness. Не добавляйте новые live-тесты без
явной необходимости и не запускайте их в CI.
